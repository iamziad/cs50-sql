* LIKE: string matching
# 'string' -> match string literally
# '%'      -> match any string
# '_'      -> match single character

#+begin_src sqlite :db "~/Projects/cs50-sql/longlist.db" :colnames yes
SELECT "title" FROM "longlist"
WHERE "title" LIKE '%love%';  -- matchs ' `any string` love `any string` '
#+end_src

#+RESULTS:
| title                      |
|----------------------------|
| Love in the Big City       |
| More Than I Love My Life   |
| Love in the New Millennium |
| Die, My Love               |

#+begin_src sqlite :db "~/Projects/cs50-sql/longlist.db" :colnames yes
SELECT "title" FROM "longlist"
WHERE "title" LIKE 'The %'  -- matchs ' `The `any string` '
LIMIT 5;
#+end_src

#+RESULTS:
| title                                 |
|---------------------------------------|
| The Gospel According to the New World |
| The Birthday Party                    |
| The Book of Mother                    |
| The Books of Jacob                    |
| The War of the Poor                   |

* Aggregation Functions, ROUND, AS
** COUNT, AVG, SUM, MIN, MAX

- الـAggregate functions هي دوال بتجمع فيم كل الصفوف وترجع فيمة واحدة في الاخر
- الـScalar functions هي دوال بتاخد قيمة واحدة وتعمل عليها عملية حسابية.
- الـAS keyword بتعمل alias لاسماء الـcolumns والـtables.

- AVG
#+begin_src sqlite :db "~/Projects/cs50-sql/longlist.db" :colnames yes
SELECT AVG("rating") FROM "longlist";
#+end_src

#+RESULTS:
|      AVG("rating") |
|--------------------|
| 3.7537179487179491 |

- AVG, rounded - ROUND (scalar function)
#+begin_src sqlite :db "~/Projects/cs50-sql/longlist.db" :colnames yes
SELECT ROUND(AVG("rating"), 2) FROM "longlist";
#+end_src

#+RESULTS:
| ROUND(AVG("rating"), 2) |
|-------------------------|
|                    3.75 |

- AS
#+begin_src sqlite :db "~/Projects/cs50-sql/longlist.db" :colnames yes

|----------------|
